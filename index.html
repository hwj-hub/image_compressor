이렇게 쓰세요

  1. 사진을 넣습니다.한 번에 여러 장을 고르거나, 캡처를 Ctrl+V로 붙여 넣어도 됩니다.
  2. 목표 용량을 고릅니다.제출처가 요구하는 값을 그대로 넣으세요. 100KB·200KB·300KB가 가장 많습니다.
  3. 규격이 정해져 있으면 크기를 바꿉니다.증명사진은 정확한 픽셀로 바꾸고 3×4cm(354×472) 또는 3.5×4.5cm(413×531)를 고릅니다.
  4. 줄인 뒤 저장합니다.한 장이면 [저장], 여러 장이면 [ZIP으로 전체 저장]이 편합니다.

자주 묻는 질문

제 사진이 어딘가로 업로드되나요?

아니요. 모든 처리는 브라우저 안(내 기기)에서만 일어납니다. 서버로 전송되는 데이터가 전혀 없어서, 페이지를 연 뒤 인터넷을 꺼도 그대로 동작합니다.

100KB 이하로 정확히 맞춰지나요?

먼저 품질을 이진 탐색으로 자동 조절해 목표에 가장 가까운 값을 찾고, 그래도 목표를 못 맞추면 해상도를 단계적으로 줄여 재시도합니다. 목표 달성에 실패하면 결과에 노란색으로 표시됩니다.

원서접수·증명사진 규격은 어떻게 맞추나요?

크기를 정확한 픽셀(가운데 잘라내기)로 바꾸고 증명 3×4cm(354×472) 또는 여권 3.5×4.5cm(413×531)를 고르세요. 형식은 JPG, 목표 용량은 기관 요구값(보통 100~300KB)으로 두면 됩니다.

아이폰 HEIC 파일이 안 열려요

휴대폰에서 바로 고르면 대개 잘 열립니다. 아이폰은 사진 보관함의 사진을 넘겨줄 때 JPG로 바꿔 주기 때문입니다. 막히는 쪽은 HEIC 파일을 PC로 옮긴 다음입니다 — 윈도우의 크롬·엣지는 이 형식을 열지 못합니다(맥 사파리는 열립니다). 휴대폰에서 줄여서 옮기거나, 아이폰 설정 › 카메라 › 포맷 › 높은 호환성으로 바꿔 앞으로 찍는 사진을 JPG로 남기세요. 갤럭시도 카메라의 고효율 사진을 켜 두면 같은 일이 생깁니다.

네이버·카카오톡 앱에서 열었더니 저장이 안 돼요

앱 안에 뜨는 화면은 내려받기 기능이 없는 WebView라서, 줄인 사진을 받을 수 없습니다. 위쪽 안내 창의 「크롬에서 열기」(아이폰은 「주소 복사」)를 눌러 일반 브라우저로 옮긴 다음 사용하세요. 아이폰은 오른쪽 아래 메뉴 → 다른 브라우저로 열기도 됩니다.

위치정보(EXIF)는 남나요?

남지 않습니다. 다시 그려서 저장하는 방식이라 촬영 위치·기기 정보 같은 메타데이터가 모두 제거됩니다. 회전 방향만 올바르게 반영됩니다.
